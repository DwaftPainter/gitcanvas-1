# GitCanvas Free Facebook tutorial

Upload the PNGs from `Images` in order from 01 to 11. Use the English caption for each image as its Facebook description.

## Step 01. Browse README templates

**Visual**

GitCanvas homepage with **Explore Templates** highlighted.

**Caption**

Visit https://gitcanvas.avenlab.tech and select **Explore Templates** to browse layouts for your GitHub profile README.

## Step 02. Select a free template

**Visual**

The **Student & Intern Starter** card with the **FREE** label and **Use Template** highlighted.

**Caption**

Find **Student & Intern Starter**, check that it has the **FREE** label, and select **Use Template** to open it in the Builder.

## Step 03. Personalize your README

**Visual**

The **Full Name** and **Bio / Summary** fields and the **Visual Preview**.

**Caption**

Update your name and bio in the **Profile** tab. Use **Social**, **Tech Stack**, and **Projects** to replace the sample links, skills, and projects with your own. Review your changes in **Visual Preview**.

## Step 04. Copy the Markdown

**Visual**

The export button displaying **Copied Markdown!**.

**Caption**

Select **Copy Markdown** in the Builder. The **Copied Markdown!** confirmation means the README content is ready to paste into GitHub.

## Step 05. Open your repositories

**Visual**

Numbered markers identify the GitHub avatar and the **Repositories** menu item.

**Caption**

Sign in to GitHub. Select your avatar in the upper-right corner, then choose **Repositories** from the account menu.

## Step 06. Start a new repository

**Visual**

The green **New** button on the **Repositories** page.

**Caption**

Select **New** on the **Repositories** page. If your account already has a public repository named exactly after your GitHub username, open it and continue to Step 8.

## Step 07. Configure your profile repository

**Visual**

Four markers identify the owner and repository name, visibility, README toggle, and creation button.

**Caption**

Choose your personal account as the owner and enter your exact GitHub username as the repository name. Set visibility to **Public**, turn on **Add README**, and select **Create repository**.

## Step 08. Open the README editor

**Visual**

A wider repository view with **Edit README** outlined in teal.

**Caption**

Select **Edit README** on the repository page. For an existing profile repository, open `README.md` in the repository’s root and select the pencil icon.

## Step 09. Paste into README.md

**Visual**

The starter text is selected in the editor and **Paste** is highlighted.

**Caption**

Replace the starter text with the Markdown you copied from GitCanvas. If you are updating an existing README, keep any sections you want to reuse. Select **Preview** to check the layout, icons, and project links before saving.

## Step 10. Commit README changes

**Visual**

The confirmation dialog with the `main` branch option and the green **Commit changes** button marked.

**Caption**

Select **Commit changes…** and enter a short message, such as `Update profile README`. Select **Commit directly to the main branch**, then select the green **Commit changes** button to save.

## Step 11. Verify your saved README

**Visual**

The saved `README.md` rendered in the repository’s **Preview** tab.

**Caption**

The saved README is shown in the repository. To verify how it appears to visitors, open `github.com/<your-username>` and check the **Overview** tab.
